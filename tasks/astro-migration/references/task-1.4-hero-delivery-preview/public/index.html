Why this exists

Canvas precision, without video seeking.

This isolated delivery build uses the human-approved wide master above 768px and the close companion below it. It draws an AVIF sequence into a canvas, uses a final-frame poster before interaction, caps the in-memory image cache, and never installs a scroll lock.

Drag the control, scroll through the stage, resize across the 768px breakpoint, and use the failure control. Reduced motion keeps the poster visible while the page remains completely scrollable.

Native scroll is intentionally left untouched.
